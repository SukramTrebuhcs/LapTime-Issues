# LapTime iOS - Anleitung

## Ziel der App
LapTime misst Rundenzeiten automatisch mit der iPhone-Kamera. Du startest die Erkennung, die App erkennt Bewegungen an der Start/Ziel-Linie und schreibt die Rundenzeiten ins Leaderboard.

## Voraussetzungen
- iPhone mit installierter LapTime-App.
- Sicht auf die Strecke (Start/Ziel-Linie).
- Optional: tvOS-Leaderboard-Host im gleichen Netzwerk.

## Ersteinrichtung
1) App starten.
2) Kamerazugriff erlauben.
3) Optional: "Lokales Netzwerk" erlauben (nur bei local network mode).
4) Tab "Setup" oeffnen und ausfuellen:
   - Fahrername (Pflicht).
   - Rennen auswaehlen oder anlegen.
   - Rundenzahl setzen.
   - Optional Fahrzeug auswaehlen.

## Rennen fahren
1) iPhone stabil platzieren, Kamera auf die Start/Ziel-Linie ausrichten.
2) Tab "Race" oeffnen.
3) "Start" tippen, die Bewegungserkennung laeuft.
4) Erste Bewegung startet Runde 1.
5) Jede weitere Bewegung zaehlt als neue Runde.
6) Nach der eingestellten Rundenzahl endet das Rennen automatisch.

## Leaderboard
- Der Tab "Leaderboard" zeigt alle gemessenen Zeiten.
- Bei aktivem Local-Network-Modus werden Zeiten mit dem Host synchronisiert.

## Wichtige Einstellungen
- Sound: im Setup aktivieren/deaktivieren und Effekte waehlen.
- Local Network Only: aktiviert die Synchronisation im lokalen Netzwerk.
- Reset: loescht aktuelle Renndaten und Rundenzeiten.

## Tipps fuer bessere Erkennung
- Gleichmaessiges Licht, keine starken Reflexionen.
- Kamera leicht erhoeht und stabil platzieren.
- Strecke sauber im Bild halten, keine schnellen Schatten im Hintergrund.

## Fehlerbehebung
- Keine Erkennung: Kamera auf die Strecke ausrichten, Licht pruefen.
- Kein Sync: Local-Network-Rechte pruefen, Host im gleichen WLAN.
